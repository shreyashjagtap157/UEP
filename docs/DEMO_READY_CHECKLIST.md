# Demo readiness checklist

- [ ] Web lint passes
- [ ] Web production build passes
- [ ] Backend verify passes
- [ ] Vulnerability scan passes or documented non-blocking findings are remediated
- [ ] Student can submit and later see graded result
- [ ] Teacher sees only assigned classes and learners
- [ ] Client sees only its organization data
- [ ] Developer sees release/integration telemetry without learner data
- [ ] Administrator can manage tenant data according to permissions
- [ ] Guardian sees only the linked learner
- [ ] Cross-role changes propagate where intended
- [ ] Cross-role unauthorized data does not propagate/appear
- [ ] Refreshing the browser does not revert persisted demo changes
